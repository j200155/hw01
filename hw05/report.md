# 实验报告：极简CNN与LeNet-5在MNIST上的对比实验

## 1. 文章学习摘要
本次实验基于公众号文章中的极简CNN代码，完成了手写数字识别任务，并在此基础上实现了经典的LeNet-5网络进行对比。
- 极简CNN仅包含1个卷积层、1个池化层和1个全连接层，结构简单，训练速度快。
- LeNet-5是1998年提出的经典CNN架构，包含2个卷积层、2个池化层和3个全连接层，是现代CNN的基础。
本次实验的目的是对比两种网络在MNIST手写数字分类任务上的性能差异，加深对卷积神经网络结构设计的理解。

## 2. LeNet-5结构说明
LeNet-5的结构如下：
1.  **Conv1**: 输入1通道，输出6通道，卷积核5×5，padding=2 → 输出尺寸28×28×6
2.  **Pool1**: 2×2最大池化，步长2 → 输出尺寸14×14×6
3.  **Conv2**: 输入6通道，输出16通道，卷积核5×5 → 输出尺寸10×10×16
4.  **Pool2**: 2×2最大池化，步长2 → 输出尺寸5×5×16
5.  **FC1**: 全连接层，16×5×5 → 120
6.  **FC2**: 全连接层，120 → 84
7.  **FC3**: 全连接层，84 → 10（分类输出）
激活函数使用ReLU，损失函数为交叉熵损失，优化器为Adam。

## 3. 两次实验的超参与结果

## 4. 极简CNN与LeNet-5对比
| 对比维度       | 极简CNN                  | LeNet-5                  |
|----------------|--------------------------|--------------------------|
| 网络深度       | 1个卷积层+1个全连接层    | 2个卷积层+3个全连接层    |
| 参数数量       | 约3.2万                  | 约6.2万                  |
| 训练速度       | 更快（每轮约10秒）       | 稍慢（每轮约12秒）       |
| 最终测试准确率 | 约98.3%                  | 约98.6%                  |
| 过拟合情况     | 轻微过拟合（训练/测试差约0.8%） | 过拟合更轻（差约0.5%） |
| 特征提取能力   | 仅提取低级边缘特征       | 可提取更复杂的组合特征   |

结论：LeNet-5由于更深的网络结构和更多的参数，在MNIST上的泛化性能略优于极简CNN，且过拟合现象更轻，但训练时间稍长。
